import { useEffect, useState } from 'react';
import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

export function Variante({ n, children }) {
  const [attiva, setAttiva] = useState(1);
  useEffect(() => {
    const v = new URLSearchParams(window.location.search).get('variante');
    setAttiva(v === '2' ? 2 : 1);
  }, []);
  return attiva === n ? <div data-variante={n}>{children}</div> : null;
}

# Quaderno — pagina di test

Sandbox del quaderno (piano `pm/piano-2026-11-quaderno.md`). La usa
`npm run quaderno:prova`: non cambiare le frasi senza aggiornare lo script. Con
`?variante=2` il paragrafo della sezione «Riscrittura» cambia come dopo una
correzione della lezione.

## Una citazione unica

La biblioteca della scuola apre alle otto e chiude quando l'ultimo lettore se ne va.
Madama Pince la chiama "il mio regno", e nessuno ha mai avuto il coraggio di
contraddirla.

## Frasi ripetute

### Primo scaffale

Sul primo scaffale stanno gli atlanti, rilegati in pelle verde.
Ogni volume ha il suo posto e nessuno lo sposta.
I più consultati sono quelli delle montagne.

### Secondo scaffale

Il secondo scaffale ospita i dizionari, dal più vecchio al più nuovo.
Ogni volume ha il suo posto e nessuno lo sposta.
Il dizionario di latino ha la copertina consumata agli angoli.

### Terzo scaffale

In fondo alla sala, il terzo scaffale raccoglie i quaderni degli studenti.
Ogni volume ha il suo posto e nessuno lo sposta.
Qualcuno, una volta, ci ha nascosto una lettera d'amore.

## Codice nella prosa

Per contare i libri basta `len(scaffale)`, e il valore `None` indica uno scaffale
ancora vuoto. L'istruzione `print("ciao")` scrive sullo schermo.

## Un runner in mezzo

Prima del programma c'è questa frase, che si può evidenziare.

```py live
scaffale = ["atlante", "dizionario", "quaderno"]
print(len(scaffale))
```
