# Python Doesn't Byte

> Libro di testo digitale open source per imparare Python, pensato per gli
> indirizzi Informatica e Liceo Scienze Applicate della scuola superiore
> italiana. Contenuti in italiano, codice eseguibile in pagina, licenza
> CC BY-NC-SA 4.0. Autore: Marco Farina / Rainbow Bits.

Il libro è organizzato in quattro volumi (Programmatore, Artefice, Archivista,
Apprendista), pubblicati man mano che le lezioni sono pronte. Le lezioni
includono esempi Python eseguibili direttamente nel browser (runtime Brython),
query SQL eseguibili in pagina e quiz.

Ogni lezione ha anche una versione in testo semplice, ripulita dai componenti
interattivi: basta sostituire la barra finale dell'URL con `.txt` (per esempio
`/archivista/le-chiavi/` → `/archivista/le-chiavi.txt`).

Questo file è generato a ogni build dalle pagine pubblicate: le lezioni
elencate qui sotto sono tutte e sole quelle online.
